# Security policy

## Supported versions

Only the latest `main` branch is currently supported. This project has not made a release yet.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use the repository host's private security reporting mechanism when available, or contact the maintainers privately before sharing exploit details.

Include the affected commit or version, reproduction steps, impact, and any mitigation you have identified. Reports are acknowledged as soon as practical and investigated before public disclosure.

The project treats SSRF, private-network access, unbounded resource use, credential leakage, unsafe redirect handling, and nondeterministic or silently weakened security policy as security issues.
